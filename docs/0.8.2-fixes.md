# 0.8.2 native contracts and limits

Source reference: themrdemonized/xray-monolith commit c57fe5b9fab4fe0506659db03137c52d2500eb2f (2026.10.11). Candidate based on accepted 0.8.1 end-user cleanup, without experimental API. No native or third-party core scripts are overwritten.

- WeaponStatMgun.cpp CreateSkeleton reads rotate_x_speed and rotate_y_speed from mounted_weapon_definition, defaults 10 degrees/sec, converts to radians. Explicit profiles choose 60 pitch / 90 yaw. Both userdata includes change; prepared model bytes do not.
- WeaponStatMgunFire.cpp IsReloadConsume defaults false when reload_consume is absent, independently of unlimited_ammo. ReloadMagazine only removes ammunition via CWeaponAmmo::Get when both consumption is enabled and unlimited is false. Explicit unlimited_ammo=false plus plmg_mounted.reload_consume enables that native path while occupied. It looks for actual compatible CWeaponAmmo in the operator inventory; no scripted item removal, refill or duplicated bookkeeping is added.
- Critical initialization boundary: WeaponStatMgun.cpp net_Spawn calls SetAmmoType before there is an Owner. SetAmmoType invokes ReloadMagazine, whose consuming path dereferences GetInventory(). A literal reload_consume=true is therefore unsafe at construction. The callback must return false with no owner, true with an operator. Native spawn then restores the server ammunition count; it does not represent a player reload. Lua fixtures cannot execute native GetInventory/CWeaponAmmo; inventory conservation requires the supplied native test plan.
- WeaponStatMgun.cpp computes ExitPosition by transforming model-userdata exit_position through XFORM. Actor.cpp detach_Vehicle first activates the character box at its current position, then sets movement to ExitPosition and ExitVelocity without testing that final destination. holder_custom.h supplies zero ExitVelocity; this is not evidence of an intentional throwing impulse. The old offset moved feet 0.5 m rearward, which can intersect geometry and trigger collision correction.
- Set exit_position to the same (0,-1.15,-1.5) local feet offset used by SetActorOffsets. Probe floor, standing headroom and body-radius cross sections behind the gun before placement; recheck the actual native ExitPosition before mounting and before native Use dismount. These are conservative STATIC-only rays (flag 2), not a native capsule sweep. Sparse probes cannot guarantee freedom from every static shape or moving object. Do not claim the screenshot root cause is proven or underground exits are solved until tested.
- Refuse unsafe placement before creating/consuming a gun and before entry; an old unoccupied gun remains pickable. If obstruction appears while occupied, retain native attachment and show a warning instead of forcing an exit or teleport. Clear native exits pass through unchanged. Dynamic obstruction recovery remains an engine/game-test boundary.

Verification: source profiles, nine-script compilation, 18 lifecycle, 63 preview/menu, 40 conversion, 40 pickup/return, 3 quiet/error-log and 13 standing/exit assertions. The author reports the fixes working after the correct standalone test. The supplied X-Ray log confirms PKM/MG42 PLMG sections and no CtZ gun backend. Detailed ammo conservation and collision behavior remain primarily user-observed rather than independently measurable from the quiet log.
